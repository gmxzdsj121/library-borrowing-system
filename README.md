## 技术选型

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 语言 | Python 3.11+（开发环境 3.14） | 课程已学，标准库能力足够 |
| Web 服务 | `http.server.ThreadingHTTPServer` | 无网络，不装第三方包也能跑 |
| 数据库 | SQLite 3（`sqlite3` 标准库） | 单文件、免安装，便于随仓库演示 |
| 口令安全 | `hashlib.pbkdf2_hmac`（SHA-256，120000 轮，16 字节盐） | 满足课程"口令加密存储"底线要求 |
| 会话 | `secrets.token_urlsafe(32)` + HttpOnly Cookie | 30 分钟不活跃自动过期 |
| 测试 | `unittest` | 无第三方依赖，`python test/run_tests.py` 一键执行 |

`requirements.txt` 中不含任何第三方依赖，克隆后即可运行。

## 目录结构

```
library-system/
├── src/
│   ├── app.py                  # HTTP 服务入口与路由分发、角色权限矩阵
│   ├── config.py               # 全局配置（会话、借阅、罚款参数）
│   ├── common/                 # 公共工具：安全、校验、日志
│   ├── controller/             # 控制器层：auth / book / borrow / reservation / stats / notice
│   ├── service/                # 业务逻辑层：auth / book / borrow / reservation / stats / notice
│   ├── dao/                    # 数据访问层：user / book / borrow / reservation
│   ├── db/                     # 建表脚本 schema.sql、连接封装、初始化脚本
│   └── web/                    # 页面模板与静态资源
├── docs/
│   ├── 需求规格说明书.md        # SRS（LIB-SRS-001）
│   ├── 数据库设计.md            # E-R 描述与字段说明（LIB-DB-001）
│   ├── 迭代计划.md              # 三轮迭代安排
│   ├── report/                 # 期末综合实践报告 docx
│   └── uml/img/                # 需求分析与详细设计图（png）
├── test/                       # 44 条测试用例
├── data/                       # 运行时生成的 library.db（此数据不提交上传）
├── logs/                       # 业务日志（此数据不提交上传）
├── start.py                    # 启动脚本
└── README.md
```

分层依赖方向：`controller → service → dao → db`，`common` 被各层调用，反向依赖一律不允许。

## 运行方式

```bash
# 1) 初始化数据库（建表 + 演示账号 + 示例分类）
python -m src.db.init_db

# 2) 启动服务（默认 http://127.0.0.1:8000）
python start.py

# 也可以用模块方式启动，或指定端口（第一个参数即端口）
python -m src.app
python start.py 8080
```

浏览器打开 `http://127.0.0.1:8000/login` 即可。

## 迭代一已实现的内容

1. 11 张基础表的建表脚本：账号、读者档案、会话、业务日志、分类、书目、复本、借阅记录、预约、罚款、通知；
2. 数据库连接封装：统一开启外键约束、Row 工厂、上下文内提交与回滚；
3. 读者自助注册：登录名 / 真实姓名 / 手机号 / 口令四类校验，弱口令拒绝，登录名唯一；
4. 登录与注销：口令散列比对（常量时间比较），连续 5 次失败锁定 15 分钟，冻结账号拒绝登录，会话 30 分钟过期；
5. 会话鉴权：HttpOnly Cookie 携带令牌，未登录访问受保护页面返回 401 并按角色跳转；
6. 业务操作日志：注册、登录、登录失败、注销写入 `sys_audit_log`，同时落 `logs/business.log`；
7. 登录、注册、主页三个页面（浅绿主题，响应式宽度）；
8. 29 条测试用例：口令安全、注册登录业务分支、接口层鉴权。

## 迭代二已实现的内容

1. 图书管理：书目新增（ISBN 唯一校验）、复本新增（条码唯一）、分类查询、按书名/作者/分类检索与分页、书目详情与复本列表；
2. 借阅登记：图书馆管理员办理借书，四项资格校验（在借数上限、无逾期、无未结清罚款、信用分≥60）+ 复本可借校验，写入借阅记录并更新复本状态与可借数；
3. 归还处理：按条码归还，计算逾期天数（扣除 3 天宽限期），逾期则生成罚款单并扣信用分 2 分，回置复本状态与可借数；
4. 逾期罚款：罚款金额 = 逾期天数 × 0.5 元/天，图书馆管理员可缴纳，审核统计管理员可减免；
5. 续借：读者自助续借，单条借阅最多续 2 次，已逾期或被他人预约时禁止；
6. 预约借书：读者预约无可借复本的图书，入队并返回队列号；归还时自动将队首预约置为 READY 并保留 3 天；读者可取消未完成预约；
7. 角色权限区分：读者（检索/借阅记录/续借/预约）、图书馆管理员（借书/归还/图书管理/罚款缴纳）、审核统计管理员（罚款减免）；
8. 新增 6 个页面：图书检索、我的借阅、借阅办理台、归还办理台、图书管理台、罚款管理台；
9. 新增 3 条借阅子系统冒烟测试，累计 32 条测试全部通过；
10. 报告第3章（体系结构、界面、详细设计、数据库设计）与第4章 4.1～4.4 完成。
